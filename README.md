# سوقنا — نموذج متجر تجريبي

واجهة متجر عربية RTL قابلة للتشغيل محليًا. تشمل تصفح المنتجات، حساب بائع/مشتري عشوائي، سلة وطلبات بمراحل متابعة، إدارة المنتجات والصور، مساعد اقتراح/تنقيح محلي، استوديو خطة تسويق، ولوحة إدارة تجريبية لإدارة الحسابات والبائعين والمنتجات والطلبات وعرض مؤشرات محلية.

## التشغيل

المتطلبات: Node.js 22.12 أو أحدث وnpm.

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`؛ يتحول المسار الرئيسي إلى المتجر. لبناء ملفات الموقع الثابتة:

```bash
npm run build
npm run preview
```

توجد نواتج البناء في `dist/`.

## طبيعة بيانات التجربة ولوحة الإدارة

لا يستخدم المشروع Firebase أو Express أو API أو قاعدة بيانات. لا يوجد تسجيل حقيقي ولا تُرسل بيانات الدخول أو الصور إلى خادم. يختار الزائر «ابدأ كمشتري» أو «ابدأ كبائع» لإنشاء بيانات عشوائية مؤقتة للعرض؛ كلمة المرور والبريد مولدان محليًا ولا يصلحان لتسجيل دخول حقيقي. تحفظ المنتجات والطلبات والخطط والصور المضغوطة في `localStorage` في المتصفح الحالي، وقد تُمسح عند مسح بيانات المتصفح. الدفع غير متاح ولا يتم تحصيل أموال.

زر «لوحة التحكم» في الشريط العلوي يفتح لوحة الإدارة التجريبية. تتيح مراجعة مؤشرات العرض، وتعديل أو إيقاف أو حذف المستخدمين والبائعين، وإنشاء/تعديل/إخفاء/حذف المنتجات، وتعديل مراحل الطلبات، وتنزيل ملخص JSON لا يتضمن كلمات المرور. كل هذه الإجراءات محلية في المتصفح الحالي. لوحة الإدارة ليست محمية بتسجيل دخول أو صلاحيات، فلا تستخدم هذا النموذج لإدارة متجر حقيقي أو بيانات مستخدمين فعلية. الأرقام والرسوم مبنية على بيانات التجربة فقط وليست تحليلات سوق أو تتبعًا خارجيًا.

مساعد المنتج ومولد خطة التسويق قواعد اقتراح محلية تجريبية، وليسا خدمة ذكاء اصطناعي متصلة. راجع كل اقتراح، ولا تعتمد قيم «غير محدد» أو المعلومات العامة كمواصفات للمنتج. لا تُستخدم تقديرات الأسعار كبحث سوق أو ضمان للمبيعات.

## صفحات المشروع

- `app.html`: المتجر، تفاصيل المنتج، الحساب التجريبي، السلة والطلبات ومخطط البيانات ولوحة الإدارة.
- `seller.html`: لوحة البائع، المنتجات ورفع الصور والطلبات.
- `marketing.html`: إعداد خطة تسويق قابلة للتعديل والنسخ والحفظ المحلي.
- `src/app.js`: منطق التجربة والتوجيه والتخزين المحلي.
- `src/admin.js`: واجهة لوحة الإدارة والمؤشرات وإدارة المستخدمين والبائعين والمنتجات والطلبات.
- `src/ui.css`: التصميم العربي المتجاوب.
- `public/manus-routes.json`: تعريف الصفحات ومسارات لوحة الإدارة.
